The shell: one map, chosen by branch

No perspectives. A branch selector says what the map is about and is also the list of sessions, since a branch is where an agent works. The left pane is a drill-down: Agents (branches and sessions) first, then the selected branch's files with a dot on files an agent touches; the right pane shows code, the session's chat (sub-agents as tabs) or hunks, depending on what you last selected. Compare is a toggle that exists when a branch has a merge request.
