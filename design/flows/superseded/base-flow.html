Base: the shell, the map, files as tabs

Level 0 and 1 of the app. One shell with a branch selector, a left pane, a center tab group whose first tab is always the Map, a right pane that is always about the center's selection, and a status line. Files open as full editor tabs beside the Map; the right pane swaps between code preview and the reduced map depending on what the center shows. Every other mode is built on this.
