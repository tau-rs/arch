# ADR 0017 · Push: agents never push

- Date: 2026-10-02
- Status: accepted
- Source: `spec/arch-v1-spec.md` §13.17 (decisions of 2 Oct 2026, taken in the product chat)

## Context

The session's branch exists in a local worktree; the forge sees it only when pushed. CI is displayed, never run, by arch (spec §10).

## Decision

- Agents **never push**.
- Push happens on **create PR** or on **your click**.
- CI runs on the forge only.

## Consequences

- The forge adapter ([ADR 0018](0018-forge-github-first.md)) pushes on create PR and reads checks; the pipeline appears on the Checks tab.
- Nothing leaves the machine without a person's action, consistent with "nothing is written before you say so" (spec §1).
