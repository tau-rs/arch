# fixtures

Shared ground truth for `arch`, `arch-app` and `sett` (the repo `tau-rs/arch-fixtures` until 2026-10-21, tau-rs/arch#100; its issues moved to `tau-rs/arch`): real repositories pinned by commit, the facts arch must
extract from them (golden files, generated by `arch-analyze` and reviewed by a person), and the invariant checks.

```
repos/        ripgrep · zero2prod · zed — submodules pinned by commit (shallow); smallsvc — in-tree, ours
golden/       <repo>/sizes.json now; facts.json and views/ once arch-analyze emits them
checks/       invariants.rs — the harness, runnable now on hand-built inputs, awaiting golden data;
              invariants.md — MAP/CANVAS number → check; budgets.toml — the six budgets (ADR 0026)
scenarios/    v1-done.md — the end-to-end scenario with expected rows
tools/        measure-sizes.sh — regenerates every sizes.json
FINDINGS.md   what fixtures found that arch-design must decide (from:fixtures)
```

| pin | commit | what it is |
|---|---|---|
| ripgrep | `e89fff8` (15.2.0) | simple CLI · hexagon · 10 crates |
| zero2prod | `970987c` (main) | web app · routes, sqlx, a shared table used as a queue |
| zed | `76659a5` (v1.22.0) | large workspace · 253 crates · perf runs; V1 asserts `gpui.rs`, `editor.rs`, `project.rs` |
| smallsvc | in-tree | our order service: ship · pay · notify, every V1 flow by construction |

```
git submodule update --init --depth 1 fixtures/repos/ripgrep fixtures/repos/zero2prod   # zed only when you need it
cargo test -p arch-fixtures-checks           # the harness (checks/) and the golden runner, from the repo root
(cd fixtures/repos/smallsvc && cargo test)   # the fixture service itself
fixtures/tools/measure-sizes.sh              # after a pin bump
```

Rules (from the handoff): golden files are never regenerated silently — a change is a PR with the diff explained,
in the same PR as the engine change that moves it. Every invariant has one check. A design page's number is read from `sizes.json`, not typed.
